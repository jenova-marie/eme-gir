Services

📖 Dictionary browser

Local mirror of the electronic Pennsylvania Sumerian Dictionary (ePSD2), browsable by letter, searchable, with cuneiform glyphs rendered inline.

🔌 MCP endpoints

Five per-domain Model Context Protocol servers exposing the dictionary, the Oxford literary corpus, the CDLI artifact catalogue, and the Oracc sign list to AI agents.

📂 GitHub

Source code, build scripts, agent prompts, full setup guide. Open source under MIT (code) with data layers separately licensed — see LICENSE-DATA.md.
